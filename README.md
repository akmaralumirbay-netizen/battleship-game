# ⚓ Battleship — Морской бой

Браузерная игра «Морской бой» против компьютера на чистом HTML, CSS и JavaScript, без фреймворков, библиотек и сборки.

Проект сделан в рамках **Narxoz Incubator 2026**.

## Возможности

- 🎯 Классические правила: поле 10×10 и флот из 10 кораблей.
- 🎲 Случайная расстановка флота одним нажатием, с соблюдением правил (корабли не касаются друг друга даже углами).
- 🤖 Два уровня сложности компьютера: лёгкий и сложный.
- 💥 После потопления корабля клетки вокруг него автоматически отмечаются как промахи.
- 🔊 Звуковые эффекты для промаха, попадания, потопления, победы и поражения. Звуки синтезируются в браузере через Web Audio API, аудиофайлы не нужны.
- 💾 Автосохранение партии: если закрыть или обновить страницу, игра продолжится с того же места.
- 🏆 Счёт побед игрока и компьютера сохраняется между сессиями.

## Как запустить

Установка не требуется.

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/akmaralumirbay-netizen/battleship-game.git
   ```
2. Откройте файл `index.html` в любом современном браузере.

Игру также можно опубликовать через **GitHub Pages**: в репозитории откройте *Settings → Pages*, выберите ветку `main` и папку `/ (root)`. Через минуту игра будет доступна по ссылке вида `https://<ваш-username>.github.io/<название-репозитория>/`.

## Как играть

1. Выберите режим компьютера в списке **«Режим AI»**.
2. Нажмите **🎲 Авторасстановка**, чтобы перемешать свой флот, пока расстановка не понравится.
3. Нажмите **🚀 Начать игру**. Компьютер расставит свои корабли случайно.
4. Стреляйте, нажимая на клетки поля **«Флот противника»**.
5. При попадании вы ходите ещё раз, при промахе ход переходит к компьютеру. Для компьютера правило то же.
6. Побеждает тот, кто первым потопит весь флот соперника.

| Класс клетки | Значение                             |
|--------------|--------------------------------------|
| `ship`       | Ваш корабль                          |
| `hit`        | Попадание (корабль ранен)            |

| `miss`       | Промах или клетка рядом с потопленным кораблём |

### Кнопки

| Кнопка                   | Действие |
|--------------------------|----------|
| 🎲 Авторасстановка        | Случайно расставляет ваш флот. Во время партии скрыта. |
| 🚀 Начать игру            | Начинает партию. Во время игры превращается в «Перезапустить игру» и начинает новую партию с текущей расстановкой. |
| 🔄 Сбросить               | Завершает текущую партию без начисления очков и заново расставляет ваш флот. |

## Уровни сложности

**🐣 Лёгкий.** Компьютер стреляет в случайные клетки, по которым ещё не стрелял.

**🔥 Сложный.** Компьютер стреляет случайно, пока не попадёт. После попадания он добавляет в очередь соседние клетки (сверху, снизу, слева, справа) и добивает раненый корабль. Когда корабль потоплен, очередь очищается и компьютер возвращается к случайному поиску.

В обоих режимах компьютер не стреляет в клетки вокруг уже потопленных кораблей, потому что они отмечаются автоматически.

Уровень сложности можно поменять прямо во время партии, он сохраняется вместе с игрой.

## Сохранение данных

Игра хранит данные в `localStorage` браузера:

| Ключ                           | Что хранится |
|--------------------------------|--------------|
| `narxoz_battleship_state_v6`   | Текущая партия: корабли, выстрелы, чей ход, очередь целей AI и уровень сложности. Удаляется после окончания партии или сброса. |
| `narxoz_battleship_score_v6`   | Общий счёт побед игрока и компьютера. |

Чтобы обнулить счёт, удалите эти ключи в инструментах разработчика (*DevTools → Application → Local Storage*) или очистите данные сайта. Если `localStorage` недоступен (например, в некоторых режимах инкогнито), игра продолжит работать, просто без сохранения.

## Технологии

- **HTML5**: разметка страницы.
- **CSS3**: оформление.
- **JavaScript (ES6+)**: вся игровая логика в одном файле, обёрнутом в IIFE, чтобы не засорять глобальную область видимости.
- **Web Audio API**: генерация звуков.
- **localStorage**: сохранение партии и счёта.

## Структура проекта

```
battleship/
├── index.html   # Разметка: панель управления, статус, два игровых поля
├── styles.css   # Стили
├── script.js    # Игровая логика, AI, звуки, сохранение
```

### Основные части `script.js`

| Функция / объект                         | Назначение |
|------------------------------------------|------------|
| `SoundEngine`                            | Синтез звуковых эффектов через Web Audio API |
| `generateRandomFleet`, `canPlaceShip`    | Случайная расстановка флота с проверкой правил |
| `handlePlayerShot`                       | Обработка выстрела игрока |
| `computerTurn`, `getAITarget`            | Ход компьютера и выбор цели |
| `addNeighborsToAIQueue`                  | Логика «добивания» в сложном режиме |
| `markSunkShip`                           | Отметка потопленного корабля и клеток вокруг него |
| `saveGameState`, `loadGameState`         | Сохранение и восстановление партии |
| `loadScore`, `saveScore`                 | Работа со счётом |

## Идеи для развития

- Ручная расстановка кораблей (перетаскивание и поворот).
- Более умный AI: определение направления корабля после второго попадания и стрельба «в шахматном порядке» при поиске.
- Кнопка включения и выключения звука.
- Сброс счёта из интерфейса.
- Режим игры для двух человек.
